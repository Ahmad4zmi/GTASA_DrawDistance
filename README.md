# GTA:SA Draw Distance (v2.10 x64)

An updated version of the original [GTASA_DrawDistance](https://github.com/AndroidModLoader/GTASA_DrawDistance) mod.

This repository provides a fix/update for the StreamDistance mod, specifically tailored for the **x64-bit** version of the game.

## ⚠️ Compatibility
**This mod is ONLY compatible with GTA: San Andreas v2.10 (x64bit).**
It will not work on older versions like v2.00 or the 32-bit versions.

## Installation
1. Download the latest release from the Releases tab (or compile the source).
2. Place the `StreamingFix64.so` into your GTA:SA `mods` folder.
3. Launch the game.
4. Adjust the settings in inside Display option.
